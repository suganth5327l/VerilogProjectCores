# FPGA Design Project

> **Objective:**  
> This is a self-learning project where I attempt to design my own FPGA. The primary goal is to understand of FPGA architecture of the FPGAs I own.
> 
**Tools**
> The toolchain I use will either consist of OpenSource toolset whic includes but not limited to qflow , icarus verilog,qtkwave and vs code with verilog extension.
> 
> Or of the Cadence Design Suite with irun ,RTL Ulter Compiler, Encounter RTL-GDSII  and Virtuoso with gpdk90.
